Investigación sobre HTML, CSS y JavaScript

¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje que estructura el contenido de las páginas web.

¿Qué es CSS?

CSS (Cascading Style Sheets) define la apariencia visual del contenido de una página web, como colores, fuentes y disposición.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite añadir interactividad a una página web, como botones, animaciones y validaciones.
